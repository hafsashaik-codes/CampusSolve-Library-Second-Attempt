# CampusSolve - Library Record Application

## Project Description
CampusSolve is a Python-based library record management application. It helps manage books, student details, issue records and returns.

## Features
1. Add new books
2. View available books
3. Register students
4. View student records
5. Issue books
6. Return books
7. View transaction history
8. Search library records
9. View library statistics
10. Export CSV reports
11. Import books using CSV
12. Load sample demonstration data

## Technologies Used
- Python
- JSON
- CSV
- File Handling
- Date and Time Module

## How to Run
Open the terminal and execute:

    python campus_solve.py

Enter 12 to load demo data and 2 to display books.

## Data Storage
The program stores records in library_records.json and exports reports into the library_reports folder.
